# Papus-Hunters
Fangame de Monster Hunter

El objetivo es realizar un juego que sea compatible con el emulador de Nintendo 3DS, "Citra", o sea, una rom (una simulación de un cartucho de videojuego fisico).
Para esto hare un paso a paso hasta que el juego sea finalmente jugable, siendo el primero de estos darle una rom de "Monster Hunter 4 Ultimate" (un juego de 3DS) para asi darle un esqueleto a la IA desde donde partir y que facilitar su compatibilidad con "Citra"
